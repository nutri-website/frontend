# NutriBox Qatar Frontend

Premium eCommerce frontend for **NutriBox Qatar** – a modern online store for sports nutrition and beauty products.

🌐 **Live Website:** https://nutribox.qa
 
## Features

- ⚡ Fast React + Vite frontend
- 🛒 Modern eCommerce experience
- 🌍 English & Arabic support
- 🔎 Advanced product search
- 🏷️ Shop by Brand
- 🎯 Deals & Promotions
- 📱 Mobile-first responsive design
- 💳 Secure checkout
- 🚚 Fast delivery across Qatar

## What We Built

- Premium homepage with sports-lifestyle banners
- Brand-focused shopping experience
- Product detail pages with nutrition information
- Category pages optimized for performance
- Search optimized for supplement brands
- SEO-friendly architecture

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS  
- Cloudflare
